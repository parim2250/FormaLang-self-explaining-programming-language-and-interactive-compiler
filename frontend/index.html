FormaLang language guide

Your first program

print("Hello, FormaLang!");

Statements end with a semicolon. Blocks use braces { }. Comments start with //, or sit between /* and */.

Types

TypeHoldsExample
intWhole numbers (64-bit)int count = 3;
floatDecimal numbersfloat price = 2.5;
booltrue or falsebool done = false;
stringText in double quotesstring name = "Ada";
voidNo value (functions that return nothing)void hello() { print("hi"); }

Variables and assignment

int total = 0;
total = total + 5;
total += 2;
total++;

Declare a variable before you use it. A variable declared without a value starts at zero. An int can go into a float automatically, but a float cannot go into an int. Use int(x) for that.

Operators

KindOperators
Arithmetic+ - * / %
Comparison== != < <= > >=
Logic&& || ! (bool only, short-circuit)
Assignment= += -= *= /=
Step++ -- (as statements, like i++;)

/ on two ints gives a whole number (7 / 2 is 3). % works on ints. + joins strings.

Conversions

int whole = int(2.9);     // 2, truncated toward zero
string text = string(whole) + " apples";

Convert with int(x), float(x), string(x), or bool(x).

Decisions and loops

if (score >= 50) {
    print("pass");
} else {
    print("retry");
}

while (n > 0) { n--; }

for (int i = 1; i <= 3; i++) {
    if (i == 2) { continue; }
    print(i);
}

Conditions must be bool. break leaves the nearest loop. continue skips to the next step of that loop.

Functions

int add(int a, int b) {
    return a + b;
}
print(add(2, 3));

Functions can be called before they are defined. Arguments are passed by value, so changes inside a function do not affect the caller. A function that returns a value must return on every path. Recursion works, but more than 200 nested calls stop the program with E503.

Output

print(x) shows any value in the Console. print is built in and cannot be redefined.

How a program runs

Source → Lexer → Parser → Semantic analyzer → Interpreter → Output. Open Show how it works under the editor to see each stage.

Not in this version

Arrays, structs, classes, input(), imports, closures, and ++ or -- inside expressions.
